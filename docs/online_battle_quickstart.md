# 在线对战简单 README（玩家版）

这份文档面向玩家，介绍如何快速进入在线对战，以及对战时需要注意的事项。

## 1. 开始前准备

1. 客户端版本要一致。
2. 网络尽量稳定，避免频繁切换网络。
3. 至少准备 1 套可用牌组。
4. 确认服务端可用（可向房主确认服务器地址，后面需要换到非白嫖服务器）。

## 2. 连接服务器

1. 打开客户端，进入在线对战大厅。
2. 在服务器地址输入框填入服务器地址，例如：
   - `wss://your-domain.com/ws`（公网加密）
3. 输入玩家名，点击连接。
4. 连接成功后会自动拉取房间列表。

## 3. 创建房间 / 加入房间

1. 创建方：点击创建房间，确认房间名。
2. 加入方：在房间列表选择目标房间并加入。
3. 进入等待房间后，先选择牌组。
4. 如果你选择的是本地牌组，可点击发布到云端（可选）。
5. 双方都点击准备。
6. 房主点击开始，进入对战。

## 4. 对战中注意事项

1. 以服务器判定为准，不要同时多次重复点击同一操作。
2. 出现交互步骤时（如选目标、分配伤害、选择附能目标），请按提示完整点完确认。
3. 网络短断时，系统会尝试恢复会话；恢复期间请等待，不要连续退进房间。
4. 若对局明显卡住，优先双方退出到大厅后重进同一房间。

## 5. 常见问题

### Q1: 连接失败怎么办？

1. 检查地址是否写成 `ws://` 或 `wss://` 的完整格式。
2. 确认端口开放（默认 `9000`）。
3. 确认服务器进程正在运行。

### Q2: 看不到朋友创建的房间？

1. 双方必须连接到同一个服务器地址。
2. 点击刷新房间列表。
3. 确认房间未满、未开始。

### Q3: 进入房间后无法开始？

1. 双方都需要选择牌组。
2. 双方都需要点击准备。
3. 只有房主可以点击开始。

### Q4: 对局中断线了怎么办？

1. 推荐直接退出客户端然后重新进入匹配大厅
